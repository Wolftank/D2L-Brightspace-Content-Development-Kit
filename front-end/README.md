# front-end

Local server + browser configurator/preview. Displays the plain-language build status, accessibility findings, and TILT/UDL flags the back end produces — the check logic itself lives in `back-end/src`, not here.

This is a stub — `src/server.js` and `package.json` exist only so the CI workflow in `.github/workflows/ci.yml` has something real to run against.
