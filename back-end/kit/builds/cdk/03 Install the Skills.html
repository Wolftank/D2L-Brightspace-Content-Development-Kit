Step Three

Install the Skills

What a skill actually is

no magic involved

A skill is a folder of written instructions that Claude reads when the task matches. That is genuinely all it is. There is no plugin to install, no service to sign up for, and nothing running in the background.

What makes these ones worth having is their contents: every rule in them was measured against our own D2L, including a dozen behaviours that are either absent from the vendor documentation or contradict it. Without them, Claude will build you something reasonable that fails in ways nobody can see.

What you are installing

six skills, one toolkit

Get the kit

One folder, everything in it

Download and unzip

Download the kit d2l-content-development-kit.zip · 151 KB

Nothing to install and nothing that runs in the background. It is a folder of text files: written instructions for Claude, the checking tools, and the measurements those tools enforce.

Unzip it wherever you keep projects. The path does not matter, but keep it together: the skills call the checking tools by relative path, so splitting the folder apart breaks the gate.

# wherever you keep work
cd ~/projects
# unzip the kit here, giving you:
D2L_Code/
  skills/     the six skills
  harness/    the checking tools
  probes/     the evidence they rest on
  builds/     examples, including these pages
  docs/       design notes and planning

Point Claude at it

one command

Open a terminal in the kit folder and start Claude Code there. It will find the skills automatically, because they sit in the project it is working in.

cd D2L_Code
claude

That is the whole installation. If you would rather have the skills available in every project rather than just this one, copy the skills/ folder into your personal Claude configuration directory instead. Ask Claude to do it for you if you are not sure where that is.

Check it worked

worth thirty seconds

Run the tests before you trust it

The kit checks itself. Run this and you should see three suites pass. If they do not, something did not unzip correctly, and you want to know that now rather than halfway through building.

node harness/emulator.test.js
node harness/lint/lint.test.js

Then try the gate on one of the included examples. It should report Clean. No findings.

node harness/lint/lint.js skills/d2l-scorm-package/assets/starter --avenue scorm
If something looks wrong

Ask Claude, in the kit folder

Genuinely. It has the skills, the tools and the evidence in front of it. Say what you ran and what you saw. Fixing a broken install is the easiest thing it will do for you all day.
