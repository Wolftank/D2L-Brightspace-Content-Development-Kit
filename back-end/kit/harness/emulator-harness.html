SCORM emulator harness

Installs D2LEmulator as this page's own API before loading a real build in the iframe -- the same "API at parent depth 1" placement measured on the tenant, so a build's normal parent-chain walk finds it exactly the way it would find the real D2L player. Closes the gap noted in CDK_Review_Findings.md #11: previously the only way to get build- specific runtime coverage was a throwaway page built from scratch each time.

Serve this folder over http(s), not file:// -- both the fetch('tenant-profile.json') below and the build's own fetches need a real origin. Any static server works (python -m http.server, cors_server.py, etc.).

Pick a role and a build path, then click "Install emulator + load build".
